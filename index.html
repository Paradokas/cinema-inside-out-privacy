Политика конфиденциальности

Приложение «Кино наизнанку» (Cinema Inside Out). Редакция от 24 сентября 2026 года.

Настоящая политика описывает, какие данные обрабатываются при использовании мобильного приложения «Кино наизнанку» и веб-версии игры, размещённой на Яндекс Играх.

Какие данные собирает разработчик

Разработчик не собирает, не хранит и не передаёт персональные данные пользователей. В приложении нет регистрации, входа в аккаунт, форм обратной связи и аккаунтов. Поле ввода в игре одно — в него вводят название фильма; введённый текст сверяется с ответом на самом устройстве и никуда не передаётся.

Данные, которые хранятся на устройстве

Игра сохраняет на самом устройстве прогресс прохождения: номер текущего задания, список пройденных уровней, остаток подсказок, выбранный язык, настройки звука и вибрации. В Android-версии эти данные не покидают устройство и удаляются вместе с приложением. В веб-версии на Яндекс Играх их копия дополнительно хранится у площадки — см. ниже.

Данные, которые обрабатывают сторонние сервисы

Для показа рекламы приложение использует Yandex Mobile Ads SDK (ООО «ЯНДЕКС»), в состав которого входит система аналитики AppMetrica. Этот SDK может обрабатывать:

  • рекламный идентификатор устройства (Google Advertising ID или его аналог);
  • сведения об устройстве: модель, версия операционной системы, язык, разрешение экрана;
  • IP-адрес и данные о типе подключения к сети;
  • события показа рекламы и технические сведения о работе приложения.

Данные обрабатываются для подбора и показа рекламных объявлений, оценки их эффективности и защиты от мошенничества. Условия обработки описаны в документах Яндекса: Политика конфиденциальности Яндекса и Политика конфиденциальности в отношении партнёров рекламной сети.

Android-версия также использует AppMetrica SDK (ООО «ЯНДЕКС») для учёта установок и сеансов работы приложения. AppMetrica обрабатывает идентификаторы устройства, сведения об устройстве и операционной системе, IP-адрес и технические сведения о работе приложения и передаёт их Яндексу. Условия обработки описаны в условиях использования AppMetrica.

Веб-версия на Яндекс Играх

При запуске игры на площадке Яндекс Игры используется Yandex Games SDK. Он передаёт игре язык интерфейса пользователя, обеспечивает показ рекламы и хранит прогресс игры через Player API под анонимным идентификатором игрока, чтобы прогресс переносился между устройствами: пройденные уровни, текущее задание, остаток подсказок, выбранный язык, настройки звука и вибрации. Регистрация и вход в аккаунт Яндекса для игры не требуются. Обработка данных на площадке регулируется документами Яндекс Игр.

Дети

Игра не предназначена для целенаправленного сбора данных детей и не запрашивает у пользователя никакой личной информации.

Как ограничить сбор данных

Сброс или отключение рекламного идентификатора выполняется в настройках операционной системы устройства: раздел настроек Google или «Конфиденциальность» — «Реклама». Полное удаление приложения стирает все локально сохранённые данные.

Privacy Policy

Cinema Inside Out application. Last updated: 24 September 2026.

The developer does not collect, store or share any personal data. The game has no sign-up and no accounts. The only text field is the answer input: what you type is checked against the answer on the device itself and is never sent anywhere.

Game progress — completed levels, current task, remaining hints, chosen language, sound and vibration settings — is stored on the device. In the Android version it never leaves the device and is deleted together with the application. In the web version on Yandex Games a copy is also kept by the platform — see below.

The application uses the Yandex Mobile Ads SDK (including AppMetrica analytics) to display advertising. The SDK may process the device advertising identifier, device model and operating system version, language, screen resolution, IP address, network type and ad impression events. This data is used to select and display ads, measure their performance and prevent fraud. See the Yandex Privacy Policy for details.

The Android version also uses the AppMetrica SDK (Yandex LLC) to count installs and app sessions. AppMetrica processes device identifiers, device and operating system information, IP address and technical information about the app, and transfers them to Yandex. See the AppMetrica Terms of Use for details.

On the Yandex Games platform the game additionally uses the Yandex Games SDK, which provides the interface language, handles ad display and stores game progress through the Player API under an anonymous player identifier so that progress can be shared between devices: completed levels, current task, remaining hints, chosen language, sound and vibration settings. No Yandex account sign-in is required.

You can reset or disable the advertising identifier in your device settings. Uninstalling the application removes all locally stored data.
